## How the graphics are made (new mechanism)
- Max's flat scene engine can't move shapes inside a scene, draw a connector on, dim, or link to a word, so these graphics don't use it. **`lab/js/graphic.js` and `lab/js/slides.js` are unchanged.**
- **`lab/js/nora/stage.js`** draws them with what the raster already traces from the DOM (`svg[data-draw]` polylines, `[data-fill]` with `data-hatch`, `.graphic-label` text), the same idea as `js/site-loops.js`. It reads the slide and beat from the URL hash.
- One file per scene: `lab/js/nora/scale.js`, `lab/js/nora/two-lanes.js`. Mount with `<div class="nora-scene" data-nora-scene="<name>">` in a `.slide-visual`.
- `data-nora-target` marks the word N01's connector lands on. `data-nora-swap` takes a sentence out of the flow so the next one replaces it in place (N02).
- **Outside tab 1:** one `<script type="module" src="js/nora/stage.js">` line in the head of `lab/layout.html`, and a block at the end of `lab/css/layout.css`.
