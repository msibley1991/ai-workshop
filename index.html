Design school teaches syntax and application of creative decisions.

This knowledge enhances capabilities with AI; it does not become irrelevant.

Prompt: Draw a low-poly sphere, a pyramid and a cube in a diagonal row on a ground plane, in two-point perspective. Shade them with hatching, lit from the top left, and compose them on the rule of thirds.

Design school does not teach correct creative decisions. AI will not give you correct creative decisions.

Only you can determine what feels correct.

colours.md

# Colours

Three colours, by role.

## Palette

- Background #F4EFE6

- Text #2B211A

- Primary #C8553D

## Use

- Primary: buy buttons only

- Text on background only

- No tints or gradients

typography.md

# Typography

## Faces

- Headings: Fraunces 600

- Body: Inter 400

## Scale

- H1 56/64

- H2 36/44

- Body 18/28

- Small 14/20

## Rules

- One face per role

- Body never below 16

- Sentence-case headings

layout.md

# Layout

## Grid

- 12 columns, 1280 max

- 24 gutters, 32 margins

## Spacing

- Steps of 8: 8–64

## Sections

- Hero: full width

- Products: 3-up cards

- Footer: 4 columns

## Breakpoints

- 640: 4 columns

- 1024: 8 columns

build-component.md

# Build a component

Use when: adding a page section.

## Steps

1. Read design-system/

2. Write the markup first

3. Use tokens, never raw values

4. Check each breakpoint

5. Compare with references/

## Done when

- It sits on the layout grid

- No new colours or faces

no-slop.md

# No slop

Use when: writing copy or UI.

## Don't

- Gradients and glows

- Emoji in headings

- "Elevate your coffee ritual"

- Stock-photo placeholders

- Every section a card

## Do

- Plain, specific words

- Say what the roastery sells

grill-me.md

# Grill me

Use when: starting anything new.

## Before building

- Ask one question at a time

- Give your recommended answer

- Follow each branch to the end

- Read the folder, don't ask

## Stop when

- Every decision is agreed

- Then sum up the plan

MCP (Model Context Protocol): tools that let an LLM work directly inside other software. Often both ways.

Each task is heavy: it costs tokens and fills the context.
