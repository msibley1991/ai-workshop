Code is an unlimited canvas.

A prompt is a request. Code is a specification. The model is non-deterministic, but what it writes can be read, edited and run the same way every time. This page is a specimen for tuning how text, panels, diagrams and objects look on the emulated display.

Heading level two

Body copy should stay readable when projected. Drag the resolution down until it breaks, then back up until it holds. Select this sentence to check the highlight goes through the shaders.

Heading level three

  • Lower-resolution emulation, nearest-neighbor upscale
  • Glow, and ghosting that grows with scroll speed
  • Scanline or pixel grid, with grid-snapped scroll
