Design school teaches syntax and application of creative decisions.

This knowledge enhances capabilities with AI; it does not become irrelevant.

Prompt: Draw a low-poly sphere, a pyramid and a cube in a diagonal row on a ground plane, in two-point perspective. Shade them with hatching, lit from the top left, and compose them on the rule of thirds.

Design school does not teach correct creative decisions. AI will not give you correct creative decisions.

Platforms and templates

Current system = ∞ programs that all do similar but slightly different things for different uses.

Templates made using the web easy, but boring.

Old way = tech: hard but visuals: interesting or tech: easy but visuals: boring.

But what if it stopped being technically challenging to make what you want digitally?

But old tools had a purpose. Old tools were a bridge between traditional design techniques and digital capabilities. How can I design by just chatting to a robot? (Spoiler: Chat becomes just 10% of the process)

A single chat is limited context. Using an LLM in a project folder allows context to exist in multiple documents.

Overview (CLAUDE.md or AGENTS.md): Tells the coding agent what we’re doing and where to look. Contains a table of contents and overview of the project. Uses Markdown: legible but organised.
